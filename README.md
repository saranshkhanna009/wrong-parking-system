**WRONG PARKING SYSTEM**
The Wrong Parking System is a full-stack web application built using **Django** and **Django REST Framework** to digitize the reporting and management of parking violations.

The application provides a centralized platform where users can report wrongly parked vehicles, upload photographic evidence, and enable administrators to review and manage complaints efficiently.

This project demonstrates backend development, REST API integration, authentication, database management, and scalable software architecture while addressing a real-world parking management problem.
