# Wrong Parking System

A full-stack web application built using **Django** and **Django REST Framework** to digitize the process of reporting and managing parking violations. The platform enables users to report wrongly parked vehicles, upload supporting evidence, and allows administrators to efficiently manage complaints through a centralized dashboard.

This project demonstrates backend development, database design, REST API integration, authentication, and scalable software architecture while solving a common real-world parking management problem.

---

## Project Overview

Parking violations are often managed through manual reporting, phone calls, or paper-based records, making the process slow, inconsistent, and difficult to track.

The Wrong Parking System replaces these manual workflows with a centralized digital platform that:

- Allows users to report parking violations online.
- Maintains digital records of parking complaints.
- Enables administrators to review and manage reports efficiently.
- Provides a scalable foundation for future AI-powered parking management solutions.
